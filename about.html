Why I Created This Site

Honestly, this site started as homework for my web development class. But somewhere between writing my first heading tag and seeing an actual page show up in my browser, it turned into something I genuinely enjoy working on. I wanted a little corner of the internet that was mine, where I could introduce myself, talk about the stuff I'm into, and let people reach me without having to dig for my email.

What motivated me most was plain curiosity. I've been using websites my whole life without ever thinking about what's under the hood. Once I learned that a page is really just a text file with some tags in it, I had to try it myself. There's something really satisfying about typing code on one side of the screen and watching a real, clickable page appear on the other. Every time I learn a new tag or CSS trick, I end up adding one more thing.

I also see this as a starting point rather than a finished project. Web development feels like a skill that will keep paying off after this class ends, whether that's building a portfolio for job applications, putting a friend's small business online, or one day launching an app of my own. For now, this simple hand-written site is step one, and I plan on making it better as I go.

A page is really just a text file with some tags in it — and that's exactly what makes it fun.
